Model ranking by Macro F1

Macro F1 is the primary ranking metric because it gives each attack class equal weight and is less likely than accuracy to hide weak minority-class detection.

Interpret carefully. CICIDS2017 used an 80:20 split of a capped experimental sample, while UNSW-NB15 retained its official test set. The two absolute scores are therefore not treated as direct measures of dataset difficulty; the comparison is used to examine ranking stability and dataset dependence.

Minority-class behaviour

Aggregate metrics conceal large differences between dominant and rare attack categories.

UNSW-NB15 official test support

Class imbalance in the untouched 82,332-record official test set.

Normal, Generic and Exploits dominate the test set. Worms has only 44 examples, so its class-specific metrics are unstable.

Random Forest per-class F1

The best-Macro-F1 UNSW-NB15 model still performs very unevenly across attack categories.

Generic is detected strongly (F1 0.981), while Analysis (0.028) and Backdoor (0.055) remain weak.

Operational point. An undetected attack is usually more serious than a false alarm, although excessive false alarms can still reduce the operational usefulness of an intrusion-detection system.

Different test designs

Scores are not interpreted as a direct numerical comparison of dataset difficulty.

Capped CICIDS2017 sample

Sampling changes original class prevalence and may remove some majority-class variation.

Pre-split median imputation

CICIDS2017 imputation before the split creates a limited preprocessing-leakage risk.

Reduced XGBoost subset

The reported CICIDS2017 XGBoost run used 6,068 stratified training rows due to runtime constraints.

Unequal neural optimisation

UNSW-NB15 MLP, CNN and LSTM used one epoch with batch size 8192.

No controlled ablation

Feature selection and class weighting were not isolated experimentally, so causal credit is avoided.
